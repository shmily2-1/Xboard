4. 没有在独立 Windows 10 机器、另一台 MySQL、整机重启场景或高并发下测试。
5. 实际测试中只清理了本次自动生成的测试失败任务与测试会话，未执行 Redis 全库清空。故障注入和早期兼容排查记录仍可在本机日志中查到。
6. Windows 版不提供 Linux Horizon 进程控制或 Swoole/Octane 性能；Windows 下的队列硬超时由外部管理器实现。
